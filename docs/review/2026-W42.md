# Week 42 review — 14 October 2026

Twenty minutes, four questions. The point is to catch drift: a status entry that is no longer
true, an estimate that has slipped twice, a decision taken without being written down.

## What closed

Nothing from the board — the board itself only came into existence today, with 9 milestones
and 64 issues. What closed is the audit that made the board possible:

- **The completion plan**, `docs/plan/` — a measured audit (not a read of the README), 12
  findings with evidence, three finish lines, milestones M0–M8 with acceptance criteria, a
  risk register, and estimates in sessions rather than in optimism.
- **M0 in substance:** the 1,833 lines of profiles/projects work are committed, the repo is
  public at <https://github.com/slowyy0477/quad>, CI runs on every push, MIT licence,
  `CONTRIBUTING.md`, issue and PR templates, Dependabot.
- **The missing database types** — `src/lib/db/database.types.ts` now exists, derived from
  the migrations by `npm run db:types:local` (52 tables, 2,972 lines, no Docker, no network),
  with `docs/plan/SCHEMA.md` as the human-readable half.
- **The UI kit finished** — 9 primitives of ~22 became 22, which unblocks every remaining
  screen; the 13 Radix packages that were installed and unused are now in use or on notice.
- **Two interface defects with real consequences:** a phone user had no navigation at all
  (only their own profile was reachable), and the dark theme documented in `globals.css` had
  no switch. Both are fixed.
- **Document drift** — migration counts, the false "no credentials supplied" claim, and
  migration numbering, which now has exactly one owner (`docs/DATABASE.md`).

## What moved

Four workstreams are running in parallel, each with exclusive file ownership: people and
universities, projects and ideas, feed depth, and the safety layer (moderation, rate limits,
admin, CSP). Three more — messaging and notifications, learning/opportunities/events, and
search — are queued behind them, because this machine is a 2-core laptop and seven concurrent
TypeScript runs do not fit on it.

## What is blocked

**One thing, and it blocks the most important claim in the repository.** The Supabase project
named in `.env.local` does not resolve (`getaddrinfo ENOTFOUND`, while `supabase.com` and
`github.com` resolve fine). Creating a project needs an account login, and that is the
author's to do, not mine. Until it exists: sign-up, sign-in, Google OAuth, the profile trigger
firing on a real `auth.users` insert, and reading and writing posts have never run against
hosted Postgres. Every "not verified" line in this repo is downstream of that one step.

## Decisions taken this week, written down

1. **Three finish lines rather than one**, because "complete" is about 200 hours and there is
   no honest way to present that as a single target. Finish line A (~5 weeks) makes the
   project verified and truthful; B (~14) is the smallest version with a reason to exist; C is
   everything, only worth doing if B produces users who ask for specific items.
2. **The database-first order stays** — schema, policies, permission tests, then interface.
   The reverse produces an interface over a hole.
3. **A verification workstream is a first-class issue type** (`type:verification`), because
   most of this codebase has never met a real database, and proving that is not a lesser task.
4. **One migration number is reserved per issue**, in one table, because four documents
   guessing four different numbers is exactly how the drift started.

## Is `/status` still true?

Not yet — and it is on the M0 list deliberately, as the last item rather than the first.
`build-status.ts` still says onboarding is `planned` and profiles are `schema-only`, which the
tree already contradicts; it also cannot yet describe the settings page, the mobile
navigation or the completed UI kit. It gets one pass at the end of the feature workstreams so
that it is edited once, against a settled tree, rather than four times against a moving one.
The rule it must satisfy when that pass happens is the one it exists for: **every entry
defensible by clicking the route.**
